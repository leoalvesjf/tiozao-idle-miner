# ⛏️ Tiozão Idle Miner

Um jogo idle de mineração bem simples, feito para web com **HTML, CSS e JavaScript puro**: sem frameworks e sem instalar nada.

## Sobre o projeto
Este jogo foi criado para **aprender o básico** de desenvolvimento de jogos para web.
É um projeto pessoal, **sem fins lucrativos**.

## Como jogar
1. Baixe ou clone este repositório.
2. Dê duplo clique no arquivo `index.html`. Ele abre no navegador.
3. Clique no mineiro para cavar e ganhar moedas.
4. Junte moedas e compre uma picareta melhor para ganhar mais a cada clique.

## O que tem na versão 1
- Um mineiro que cava quando você clica nele
- Um contador de dinheiro
- Um upgrade de picareta, com preço que sobe a cada nível

## Estrutura
```
index.html   → estrutura da página
style.css    → aparência e posições
game.js      → lógica do jogo
assets/      → imagens em SVG (cartoon vetorial)
```

## Quer ajudar?
Toda ajuda é bem-vinda! 🙌
1. Faça um **fork** deste repositório.
2. Faça suas melhorias.
3. Abra um **Pull Request** explicando o que mudou.

Ideias para as próximas versões: um limite de ouro por andar com novos andares, elevador, armazém, gerente (automação) e salvar o progresso.
